## 📋 API Examples

### Assign State to School
```
PUT /api/superadmin/schools/5/assign-state/1
Response: {"message": "State assigned successfully", "stateId": 1, "stateName": "Madhya Pradesh"}
```

### Get Schools by State
```
GET /api/superadmin/schools/by-state/1
Response: [List of schools in state 1]
```

### Get Schools by District
```
GET /api/superadmin/schools/by-district/1
Response: [List of schools in district 1]
```
